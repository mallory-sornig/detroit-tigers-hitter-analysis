# Detroit Tigers Offense Analysis

This project analyzes Detroit Tigers hitters using traditional and Statcast metrics to evaluate offensive performance, quality of contact, plate discipline, and sustainability.

## Research Question

Which Detroit Tigers hitters show the strongest signs of sustainable offensive performance?

## Metrics Used

- wOBA
- xwOBA
- xBA
- xSLG
- Hard-Hit %
- Barrel %
- BB/K Ratio

## Current Analysis

The project currently includes:

- Actual vs. expected offensive performance
- Quality of contact analysis
- Plate discipline comparison

- Microsoft Excel
